# Ідеї на потім (не в роботі)

Відкладені або відхилені ідеї з обговорень. Кожна має статус і причину,
щоб не повертатися до одного й того ж.

## Оверлей: рядок на кожен трек-кандидат гонки

**Статус:** відкладено (2026-09-24), реалізувати після переходу оцінки на Δ.

Для гонки з невизначеним треком (невпевнений OCR або лише карта) показувати
в оверлеї по рядку на кожен трек-кандидат, з Δ і лічильником для кожного;
номер, карту й авто вирівнювати по вертикалі по центру:

```
1  Карта  Трек1  Авто  −1.0s  3/4
          Трек2        −2.0s  4/4
```

Кандидати — ті самі, що в чипах асистента (`AssistantService.chip_tracks`):
до 3 треків для невпевненого OCR, усі треки карти для гонки лише з картою.
Авто одне на всі кандидати — так уже працює підбір
(`_pessimistic_candidates`: оцінка авто = мінімум по треках). Гонка в цілі
P(≥3 з 5) лишається однією гонкою, а не «10 треків»: заїзд відбудеться лише
на одному з кандидатів.

## Власна σ авто з його заїздів

**Статус:** відкладено (2026-09-24).

Замість константи σ = 2 с брати стандартне відхилення останніх 10 чистих
заїздів самого авто на треку (при n ≥ 3). Стабільне авто з малою перевагою
оцінювалося б вище, «рвучке» з великою — нижче. Повернутися, якщо константа
на практиці помітно бреше.

## Типова σ треку для малих вибірок

**Статус:** відхилено (2026-09-24).

Для авто з n < 3 брати медіану σ інших авто на тому ж треку. Відхилено:
різні авто на одному треку дають зовсім різні часи, а одиничний заїзд
«заради інтересу» на непідходящому авто псував би медіану. Оцінка йде
лише по самому авто навіть при n = 1; малу вибірку видно по лічильнику «1/1».
