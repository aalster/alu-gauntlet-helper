# Редизайн таба «Налаштування»

**Дата:** 2026-08-05
**Статус:** затверджено користувачем (варіант «картки-панелі», кнопка Save лишається)

## Проблема

Усі ~12 налаштувань лежать в одному пласкому `QFormLayout` без груп: трей,
мови, хоткеї, оверлей і монітор ідуть підряд без візуальних меж. Підказка про
перезапуск стилізована хардкодом `#888`, статус «Збережено» з'являється
всередині форми і зсуває лейаут. Решта застосунку «карткова», плаский таб
випадає зі стилю.

## Рішення

### Структура

Три картки в одну колонку + рядок збереження внизу:

1. **ЗАСТОСУНОК** (`settings.section_app`) — мова інтерфейсу (+ підказка про
   перезапуск у тому ж рядку), мова гри, три трей-чекбокси (кожен на своєму
   рядку: між ними залежність enable/disable, вертикаль читається як ієрархія).
2. **РОЗПІЗНАВАННЯ** (`settings.section_capture`) — гаряча клавіша, сегментний
   вибір монітора, «Зберігати скріни» + «Відкрити теку» (рядок на всю ширину).
3. **ОВЕРЛЕЙ** (`settings.section_overlay`) — гаряча клавіша, модифікатор
   керування, слайдер прозорості зі значенням.

Внизу праворуч кнопка «Зберегти»; статус-лейбл — ліворуч від кнопки (форма
більше не стрибає). Помилка реєстрації хоткея підсвічується `style.ERROR`,
успіх — приглушеним кольором.

Колонка з картками обмежена по ширині (max 640px) і притиснута вліво, щоб на
широкому вікні рядки не розтягувались.

### Вигляд картки

- Контейнер: `QFrame` з `objectName="settingsCard"` (QFrame малює фон із QSS
  без додаткових атрибутів, на відміну від голого QWidget).
- Фон `rgba(5, 12, 40, 110)` (як у списків), рамка `1px BORDER`, радіус 8px,
  внутрішні відступи ~16px.
- Заголовок: `QLabel` з `objectName="settingsCardTitle"` — жирний, 12px,
  `TEXT_MUTED`. Текст uppercase прямо в перекладах (Qt QSS не має
  text-transform).

### Зміни по файлах

- `views/style.py` — QSS-блоки `QFrame#settingsCard`, `QLabel#settingsCardTitle`.
- `views/settings_tab.py` — хелпер `_card(title) -> (QFrame, QFormLayout)`;
  розкладка існуючих віджетів по трьох формах; статус поруч із кнопкою;
  підказка `#888` → `style.TEXT_MUTED`. Логіка (`refresh`, `on_save`,
  `on_tray_changed`) не змінюється.
- `ui_lang.py` — ключі `settings.section_app` / `section_capture` /
  `section_overlay` (en: APPLICATION / RECOGNITION / OVERLAY;
  uk: ЗАСТОСУНОК / РОЗПІЗНАВАННЯ / ОВЕРЛЕЙ; «ЗАХОПЛЕННЯ» відхилено як
  неоднозначне).

### Уточнення після першого перегляду (2026-08-05)

- Підписи мов — повні, мовою самого напису: English / Українська / Русский.
- Помилки `HotkeyEdit` не пишуться в інпут (не вміщаються) — компонент
  випромінює `error_changed(str)`, таб показує лейбл кольору `ERROR` праворуч
  від інпута. Рядки помилок/плейсхолдера перенесено в `ui_lang`
  (`hotkey.press_combo` / `hotkey.forbidden` / `hotkey.need_modifier`).

### Друга ітерація (2026-08-05)

- Одна комбінація не може виконувати дві дії: `HotkeyEdit.validator` —
  колбек, що відхиляє комбінацію з текстом помилки (`hotkey.duplicate`);
  таб перехресно порівнює інпути хоткеїв з поточним (можливо незбереженим)
  значенням сусіда.
- Кнопка «Скинути» (`settings.reset`, secondary-стиль, ліворуч від
  «Зберегти») — відкат незбережених змін через `refresh()`.
